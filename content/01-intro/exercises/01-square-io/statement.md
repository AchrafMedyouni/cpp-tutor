Read **one integer** `n` from standard input.

- If it was read successfully, print `square of N = M` where `M = N * N`.
- Otherwise (e.g. the input is `abc` or empty), print `invalid input`.

```
input:  7            output: square of 7 = 49
input:  -3           output: square of -3 = 9
input:  hello        output: invalid input
```
Inputs fit in an `int` and so do their squares.
